📱 Excited to share my latest IoT & Mobile Application Project: Virtual Fence & Livestock Monitoring System! 🐄 GPS / IoT

Managing and tracking livestock efficiently is a major challenge in modern agriculture. To solve this, I developed a smart livestock collar and mobile application system that combines Geofencing, Real-Time Location Tracking, and Health/Behavior Analytics.

🌟 Key Highlights of the Project:
📍 Real-Time Location Tracking: Integrated OpenStreetMap in a Flutter app to display live positions using the NEO-6M GPS Module.
🗺️ Custom Virtual Boundary (Geo-Fencing): Allows users to draw interactive boundaries on the map. If livestock cross the boundary, it triggers an instant audio alert (Piezo Buzzer) on the collar device over Wi-Fi (ESP8266).
📊 Behavior & Health Monitoring: Uses an MPU6050 Accelerometer/Gyroscope sensor to analyze movement patterns—helping detect cattle activities such as feeding, resting, panic, or potential illness.
🔬 Research-Inspired: Inspired by livestock behavior analytics research from the Department of Eco-Friendly Livestock Science, Seoul National University.

🛠️ Tech Stack & Hardware:
• Mobile App: Flutter, Dart, OpenStreetMap APIs
• Hardware: ESP8266 (Wi-Fi), NEO-6M GPS, MPU6050 Sensor, Piezo Buzzer
• Embedded Programming: C++ / Arduino Framework
